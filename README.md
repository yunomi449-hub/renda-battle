# 連打対決！

ブラウザで遊べる連打ゲームです。スマホにも対応しています。

▶ **遊ぶ：https://yunomi449-hub.github.io/renda-battle/**

## モード
- ⏱ **タイムバトル**（2人）：制限時間内に多く押した方の勝ち
- ⚡ **綱引きバトル**（2人）：ラインを相手陣地まで押し込んだ方の勝ち
- 🏃 **ひとりでタイムアタック**：制限時間内に何回押せるか挑戦

制限時間は 5秒／10秒／20秒 から選べます。

## 操作
| | PC | スマホ |
|---|---|---|
| PLAYER 1 | `A` キー / 画面左側をタップ | 画面の上半分をタップ |
| PLAYER 2 | `L` キー / 画面右側をタップ | 画面の下半分をタップ |
| ひとり | `A` `L` `Space` どれでも | 画面のどこでもタップ |

スマホで2人対戦するときは、机に置いて向かい合わせで遊べます。

## ランキング
モードごとにトップ10を記録します。記録はその端末のブラウザに保存されます（端末ごとに別々です）。

## 構成
`index.html` 1ファイルだけで動きます（外部ライブラリ・画像・音声ファイルなし）。
